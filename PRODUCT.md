# Product

## Register

product

## Users

TianShu is used by operators, analysts, and developers working in a tactical scenario workspace. They need dense controls, live scenario state, map context, AI command review, and runtime tools without losing situational awareness.

## Product Purpose

TianShu combines a React/Cesium command UI with a FastAPI backend runtime and MCP-accessible tactical tools. Success means users can inspect scenarios, coordinate AI-assisted commands, review runtime state, and manage tool access from one reliable operational surface.

## Brand Personality

Restrained, tactical, precise. The interface should feel like a command console for real work: dark, legible, state-rich, and deliberate.

## Anti-references

Avoid marketing-page composition, decorative hero sections, playful SaaS cards, ornamental gradients, and invented controls. The product should not look like a generic AI dashboard or a sci-fi mockup detached from operational workflows.

## Design Principles

- Make authority visible: distinguish backend runtime, local configuration, read-only tools, and writable actions.
- Keep density usable: support scanning across maps, tools, approvals, and scenario state without oversized presentation blocks.
- Prefer familiar controls: use standard tabs, lists, toggles, buttons, badges, search, and detail panels.
- Treat color as state: reserve cyan for active focus, green for online/enabled, amber/red for warnings and risk.
- Preserve operational trust: every visible metric or label must be backed by data the UI actually has.

## Accessibility & Inclusion

Target practical WCAG AA contrast for text and controls. Keep reduced-motion compatibility in mind for modal and list transitions, avoid color-only status meaning, and keep keyboard focus states visible.
